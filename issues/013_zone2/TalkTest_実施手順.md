# 室内トレーナー Talk Test 実施手順

**目的**: LT1（有酸素閾値心拍）を実測値で較正し、`config/personal.yaml` の `zone2.lt1.manual_bpm` に記録する

**前提条件**:
- 完全に回復した状態（十分な睡眠 7時間以上、RHR 安定）
- 室内トレーナー + HR モニタ（胸ストラップ推奨、精度重視）
- 所要時間: 20-30分
- 実施日時: 朝食後1-2時間、リラックス後（RHRが低い状態）

---

## 実施ステップ

### 1. セットアップ（5分）
1. 室内トレーナーを安全に設定、バイクを固定
2. HR モニタを装着（胸ストラップ＝最も正確）
3. 負荷計（ワット計またはアプリ）を表示、HR は秒単位で読める状態に
4. 5分間の軽いペダリング（Zone 1: 50-80W）で心拍を安定させる

### 2. Talk Test の実施（15-20分）

#### ステージ1: スタート（Z1 easy）
- **開始ワット数**: 80-100W（呼吸が楽、話が容易）
- **心拍**: 記録（おおむね RHR + 30-50 bpm 程度）
- **言語テスト**: 「これはテストです。話すことができます。」を2回繰り返す
- **判定**: 容易に話せるか確認。YESなら次へ。

#### ステージ2: 負荷増加（段階1）
- **ワット数を +20W（100-120W）に上げる**
- **3-5分間 継続、心拍を安定させる**
- **言語テスト**: 上記フレーズを2回繰り返す
- **判定**:
  - 容易に話せる → 次のステージへ
  - 少し息切れしている → 記録（その時の HR）して確認、もう1段階続行推奨

#### ステージ3: 負荷増加（段階2）
- **ワット数を +20W（120-140W）に上げる**
- **3-5分間 継続**
- **言語テスト**: フレーズを繰り返す
- **判定**:
  - 容易に話せる → 次へ
  - **息切れしながら話している / 単語が途切れている** → **この時点の HR が LT1（またはそれに非常に近い）**

#### ステージ4: 決定ステージ
- **ワット数を +20W（140-160W）に上げる**
- **言語テスト**: フレーズを繰り返す
- **判定**:
  - 明らかに話が困難（息切れで単語が途切れる、呼吸が荒い） → **この直前のステージの HR が LT1**

---

## HR 計測のポイント

- **計測タイミング**: 各ステージ最後の1-2分（心拍が安定した時点）で読む
- **記録方法**: スマートフォン / スプレッドシート / メモ帳に以下を記録:
  ```
  ステージ1: 80W  / HR= ___ bpm / 判定: 容易
  ステージ2: 100W / HR= ___ bpm / 判定: 容易 / やや息切れ
  ステージ3: 120W / HR= ___ bpm / 判定: やや息切れ / 困難
  ステージ4: 140W / HR= ___ bpm / 判定: 困難
  
  LT1 推定値: ___ bpm（Talk Test 困難開始時点の HR）
  ```

---

## 実測値の記録

Talk Test で確定した LT1 (bpm) を以下に記録:

```yaml
# config/personal.yaml の zone2 セクション
zone2:
  lt1:
    method: maf
    maf_base: 180
    manual_bpm: <実測したLT1を記入: 例=130>
    # 記入後、全レポートが自動的に新しい LT1 で再計算される
  band_width_bpm: 15
```

例: Talk Test で LT1 が 130 bpm と判定された場合:
```yaml
manual_bpm: 130
```

---

## 結果の確認

記録後、以下のコマンドで Zone2 帯が更新されたことを確認:

```bash
python src/lib/analytics/zone2.py
# 出力例:
# LT1=130bpm (manual), Zone2 band=[115, 130) bpm
```

再度レポートを生成すると、新しい Zone2 数値（`config/personal.yaml` の `manual_bpm` に基づく）が反映される:
```bash
python scripts/generate_body_report_daily.py --days 30
```

---

## 注意点

- **複数回実施**: 信頼度向上のため、1週間空けて2-3回実施し、平均値を LT1 とする方法も有効
- **モダリティ**: 自転車での測定値を記録（ランニングでの Talk Test LT1 と異なる）
- **条件**: 毎回 同じ時間帯（朝食後1-2時間）、同じ状態（十分な睡眠、回復状態）で実施
- **信号ノイズ**: 室内トレーナーは信号が安定しているため、Talk Test に最適な環境

---

## 予想結果

MAF 推定値 141 bpm に対し、Talk Test で **125-135 bpm** 程度の LT1 が予想されます。
その場合、現在の通勤サイクリング（100-126 bpm）が Zone2 帯 [110-135) に大きく入り、
既存の負荷で週目標の大部分が達成できる可能性が高いです。
