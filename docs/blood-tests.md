# 採血値（手入力・取得スクリプト無し）

| ファイル | 中身 |
|---|---|
| `data/blood_donation.csv` | 献血時の血液検査（血圧・肝機能・血算） |
| `data/checkup.csv` | 健康診断（身長・体重・脂質・肝機能・血算・腎機能） |

CSV が正本。結果票の写真から agent が書き、本人は LibreOffice で直接直す。
Drive の `daily_report` シートの同名タブは 2026-09 までの旧置き場で、もう書かない
（2026-11-25 に一本化。二重管理でシートが古いまま残った）。

列は結果票の並び（身体計測→血圧→脂質→肝機能→糖代謝→腎機能・尿酸→血算）。
結果票に無い項目は空欄にし、新しい項目は列を足す。

血算の推移は**両方の CSV を読んで並べる**（片方だけ見て「比較対象なし」と誤った）。
統合ファイルは作らない。名前が違う（献血 `Hb`/`RBC`/`Ht` ＝健診 `血色素量`/`赤血球数`/`ヘマトクリット値`）。
WBC は献血が百/μL（`32`＝3200/μL）、健診が/μL。PLT はどちらも万/μL の推定（2026-11 の結果票は単位の列が写っていない）。

`data/healthplanet_bp.csv` とは別物（あちらは家庭用血圧計の日次）。採血の
血圧値をあちらへ混ぜない。
