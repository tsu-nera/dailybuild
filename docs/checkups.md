# 検査の結果票（健診・献血・歯科検診）

取得スクリプトは無い。結果票を受け取るたびに、本人が撮った写真から agent が書く。
正本は CSV（dailybuild-private の `data/`）。本人は LibreOffice で直接直す。
Drive の `daily_report` シートの同名タブは 2026-09 までの旧置き場で、もう書かない。

| ファイル | 中身 | 形 |
|---|---|---|
| `data/checkup.csv` | 健康診断（身体計測・血圧・脂質・肝機能・糖代謝・腎機能・血算） | 横持ち |
| `data/blood_donation.csv` | 献血時の血液検査（血圧・肝機能・血算） | 横持ち |
| `data/dental_checkup.csv` | 歯科検診 | 縦持ち |

共通の決まり:

- 用紙で空欄の欄は空にする（推定で埋めない）
- 写真は `photo-shrink`（`~/repo/scripts`）で縮めてから置く。原寸は git に入れない
- public 側（このリポジトリ）に検査値・医院名・地名を書かない

## checkup.csv・blood_donation.csv

列は結果票の並び（身体計測→血圧→脂質→肝機能→糖代謝→腎機能・尿酸→血算）。
結果票に無い項目は空欄にし、新しい項目は列を足す。

血算の推移は**両方の CSV を読んで並べる**（片方だけ見て「比較対象なし」と誤った）。
統合ファイルは作らない。名前が違う（献血 `Hb`/`RBC`/`Ht` ＝健診 `血色素量`/`赤血球数`/`ヘマトクリット値`）。
WBC は献血が百/μL、健診が /μL（献血の値を100倍して比べる）。PLT はどちらも万/μL の推定（健診の結果票は単位の列が写っていない）。

採血の血圧は `data/healthplanet_bp.csv`（家庭用血圧計の日次）とは別物で、あちらへ混ぜない。

## dental_checkup.csv

縦持ち `date,clinic,item,value,note`。様式が変わっても列が動かないよう、項目は `item` に足す。

- `value` は用紙の記号・選択肢の文言のまま。歯式は `歯式_<FDI番号>` で `○` 処置歯・`/` 健全歯・`C` 未処置歯
- 用紙に合計欄（健全歯数・現在歯数など）があれば、歯式を数え直して一致を確かめてから書く
- 結果票の写真は `data/dental_checkup/YYYY-MM-DD_N.jpg`
